# 数据来源与更新

## UNESCO 世界遗产索引

- 英文事实字段：https://whc.unesco.org/en/list/xml/
- 中文名称：https://whc.unesco.org/zh/list/xml/
- 来源清单：https://whc.unesco.org/en/list/
- 快照日期：2026-10-18；1,273 条，其中 61 条的国家代码包含 CN。
- 源文件 SHA-256 存在 `data/unesco.json` 顶层，记录此次导入依据。
- 所有导入条目的模型状态默认 `planned`。名字中的“University”不会成为“已有校园模型”的证据。
- 主分类基于条目名称规则辅助分配，属于本站编辑标签。中文缺失时保留官方英文；常用别名与分类更正在 `data/overrides.json`。
- 不导入描述全文、图片、坐标和模型文件；世界遗产名称并非对外开放或完整景区目录的保证。

## 手工资料

40 所大学使用各自官网作为地点身份来源；不是全球高校完整清单，也不是排名。复旦、剑桥和 UT Austin 条目附上发现的三维项目入口，状态为 `external`，不冒充已验证完整模型。

历史复原条目是有来源背景的建模计划，当前没有三维文件。文学生境以原作品链接作参考。大观园为维护者提供的实际 HTML，原文件哈希在条目中。

## 核验日期的含义

`sources[].checked_at` 代表本次来源查阅记录；批量目录对应此次官方 XML 获取日期。未逐页检查的手工官网字段保留 null。`verified_at` 仅代表场景浏览验证，不推断采集日期或精度。

## 可复现更新

1. 运行 `python3 scripts/import_unesco.py --date YYYY-MM-DD`，日期填写实际审核所用日期。
2. 查看名称、数量、代码、来源及分类变化，保留人工条目和别名映射。
3. 运行 `python3 scripts/build.py`；审核新增/移除项，不因源目录数量增长自动增加已验证场景数。
4. 提交数据、文档统计及生成的 `catalog/*.md`。GitHub Actions 构建使用仓库快照，无需依赖源网站当时在线。
