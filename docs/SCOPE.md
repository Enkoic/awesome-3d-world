# 收录范围与分类

awesome-3d-world 收集可以探索的三维地点与世界，连接地点名称、在线体验、资源下载、来源精度和社区贡献。

## 六个主分类

| ID | 分类 | 范围 |
| --- | --- | --- |
| campus | 大学与校园 | 大学、中小学、书院及其校区、教学建筑群与公共空间 |
| scenic | 景区与自然景观 | 园林、山水、自然保护地、文化旅游景区及遗产地 |
| urban | 城市与街区 | 城市片区、历史街区、古镇、村落与聚落 |
| landmark | 地标与公共空间 | 代表性建筑、广场、交通建筑、博物馆及可探索的室内空间 |
| historical | 历史复原 | 真实地点在明确历史时期的重建；须说明年代、阶段与推定 |
| fictional | 架空与文学世界 | 文学、影视、游戏中的空间与有明确设定的原创世界 |

一个条目只有一个主分类，其他属性使用标签。校园建筑可以带有“地标、图书馆”标签；自然遗产不因此自动代表可开放游览的景区。UNESCO 导入条目的主分类由名称规则辅助分配，属于本项目编辑分类，欢迎纠正。

## 世界属性与地理范围

- `real`：现实地点，须明确校区、片区、单栋或室内覆盖范围。
- `historical`：历史时期的真实地点，须提供年代与依据；现存遗址模型不自动属于历史复原。
- `fictional`：虚构或文学空间，不强行标注现实坐标，不当作实测复原。
- 同名地点、不同校区和同一地点的不同时代分别建立条目；跨国系列遗产按登记条目索引，后续可以添加有明确关联的子场景。
- 国家与地区代码用于搜索和数据匹配，不构成主权或边界判断。

## 现实知名度作为优先级依据

优先收录具有可查身份的地点，例如官方世界遗产名录、官方景区资料、大学官网或可定位的文化作品。来源用于证明身份，不直接等同于知名度高低，不编造热度分数、学校排名或游客量。区域性地点和原创世界也可以收录，只要空间身份、内容和来源明确。

## 场景门槛

正式资源应能表达可辨认的空间：建筑及环境、房间与游览路径、园林、街区、校园、地形或完整虚构空间。单件家具、人物、通用材质、纯图片或只有演示视频的内容可以成为辅助资料，不计入“可浏览三维场景”。地标单体有明确身份、尺寸/空间信息及三维查看方式时也可收录。

表现形式可以是网格、体素、点云、NeRF、3D Gaussian Splatting 或程序化场景；不要求统一渲染引擎。必须准确写明文件格式和使用条件：HTML 场景不标成 GLB，代码仓库不标成已下载模型，在线平台浏览不标成自由再分发授权。

## 目录与模型分开

| status | 显示名称 | 条件 |
| --- | --- | --- |
| planned | 待收录场景 | 只有地点/世界档案，没有在本库收录的可用资源；不等于外界不存在模型 |
| external | 外部项目 | 已找到项目或数据线索，还未完成浏览、文件、范围与许可核验 |
| ready | 已验证可浏览 | 有实际可打开的三维预览或可复现运行路径，记录验证日期、资源类型、来源与局限 |
| unavailable | 资源不可用 | 已收录资源失效或撤回，保留来源和原因，不继续展示下载能力 |

“已验证可浏览”只证明场景运行，不代表测绘精度、考据完整或授权范围已经全部通过审核。下载能力由独立的 `download` 资源决定。

世界遗产名录是首批候选地点底座，不是“所有景区”的清单，也不是模型库存。大学、城市和虚构世界通过社区逐步扩展。主页必须分别显示目录数、已验证场景数和外部线索数，禁止用目录数量宣传已有模型数量。

## 首批边界

首批使用 UNESCO 英文与中文 XML 的事实字段建立世界遗产目录，并手工补充大学与文学空间。未提供中文官方名称时保留英文名称。仅保留名称、标识符、所在国家/地区、遗产类别与登记年份；不批量搬运官方图片、描述全文或外部模型文件。

大观园归入“架空与文学世界”。提供的完整 HTML 是体素文学重构，不是现实北京或上海大观园的测绘模型，也尚未提供 GLB。
