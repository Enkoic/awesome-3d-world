CURATION PRINCIPLES

六类场景，一份世界图鉴。

六类空间，一套可核验的收录标准。

01 / 场景有身份

校园、景区、城市街区、地标、历史复原与架空世界。每条只有一个主分类，其他属性使用标签。

02 / 知名度有依据

记录官方名录、学校官网或作品出处；不编造人气分数，也欢迎有特色的区域地点和原创世界。

03 / 来源与精度分开

记录实测、摄影测量、地图建模和艺术重构等来源。视觉表现与几何精度分别说明，只展示有依据的信息。

04 / 状态如实说明

目录、外部项目、可浏览场景分别计数。HTML、GLB、点云和工程分别标注，资源许可按原来源记录。

首批世界遗产目录来自 UNESCO World Heritage Centre。每条档案链接原始资料，社区通过 GitHub 持续补充三维资源。
