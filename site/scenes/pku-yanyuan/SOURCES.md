# 北京大学 · 燕园核心区

覆盖西校门、办公楼、未名湖、湖心岛、博雅塔、图书馆与静园相连片区。场景依据校方地图的相对布局、建筑资料与照片进行风格化低模重构。

交付格式为自包含 HTML / WebGL，下载后可直接离线打开；页面提供地点信息、地图、两条导览及四季和昼夜切换。
